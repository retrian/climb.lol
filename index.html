What you can do

NA only
Browse public leaderboards Search by name and explore the public directory with no login.
Own one leaderboard Create exactly one leaderboard per account, keeping the focus on your squad.

Track ranked stats See current rank, LP, winrate, top champions, and recent games.

How it stays reliable

Serverless-friendly
PUUID-first storage Every player is saved by immutable PUUID while Riot ID stays mutable for display.
Rate-limit aware Match history is stored in the database and de-duplicated by match ID.
Visibility modes Public shows in the directory, Unlisted is link-only, Private is owner-only.
Fast sharing Clean slugs and easy-to-copy links make sharing simple.
